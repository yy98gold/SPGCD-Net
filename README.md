# SPGCD-Net: Semantic Prior Guided Change Detection Leveraging Pre-trained Vision-Language Models for Remote Sensing Imagery

The dataset used in this manuscript is below：
The LEVIR-CD dataset is available at https://justchenhao.github.io/LEVIR/.
The SYSU-CD dataset is available at https://github.com/liumency/SYSU-CD.
The WHU-CD dataset is available at http://gpcv.whu.edu.cn/data/building_dataset.html.

The dataset is publicly available, and the analysis code will be released upon acceptance or formal publication of the manuscript.
